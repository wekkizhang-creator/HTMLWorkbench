# PinShot PC 截图工具设计规格

日期：2026-08-01
状态：已获用户批准，待规格复核
产品类型：PC 端截图工具高保真交互原型

## 1. 产品定位

PinShot 截贴是一款参考 Snipaste 工作方式、但采用现代桌面视觉语言的 PC 截图工具。它的核心承诺是：用户无需打开大型主窗口，即可在 3 秒内完成截图并返回原工作。

产品以“捕捉优先”为路线，核心闭环为：

`F1 → 选择区域 → 必要时标注 → Enter 复制 / F3 贴图 → 回到原工作`

第一阶段交付高保真、可点击的浏览器原型，用模拟桌面验证选区、标注、贴图和设置体验。原型不声称能够读取真实系统屏幕或注册系统级全局快捷键，但交互模型应能直接指导后续原生 Windows 实现。

## 2. 设计原则

1. **低打扰**：常用截图流程不打开设置中心或素材管理主窗口。
2. **热键优先**：所有核心鼠标操作都有键盘等价方式。
3. **就地完成**：工具栏、尺寸信息和反馈都围绕当前选区出现。
4. **渐进复杂**：默认只呈现常用动作，高级配置收纳到设置中心。
5. **本地优先**：原型不上传截图内容；后续原生应用默认本地处理。
6. **参考而不复制**：保留 Snipaste 的效率模型，更新信息架构、视觉层级和表单交互。

## 3. 目标用户与核心场景

### 3.1 目标用户

- 需要频繁截图沟通的产品、设计、研发和运营人员。
- 需要将局部信息临时置顶参考的知识工作者。
- 偏好快捷键、希望减少文件管理步骤的高频桌面用户。

### 3.2 核心场景

1. 截取窗口或自由区域后立即复制到剪贴板。
2. 使用箭头、文字、矩形或马赛克快速标注。
3. 将截图作为无边框窗口置顶在桌面。
4. 调整截图、贴图、快捷键、鼠标手势和输出偏好。

## 4. 范围

### 4.1 第一阶段必须实现

- 模拟桌面与截图蒙层。
- 悬停窗口候选与自由拖拽选区。
- 八个选区锚点、尺寸标签和像素放大镜。
- 矩形、箭头、画笔、荧光笔、文字、序号、马赛克和取色工具的可交互表现。
- 撤销、重做、复制、保存、贴图、完成和取消。
- 可移动、缩放、调透明度、锁定和关闭的桌面贴图。
- 最近截图条，用于恢复最近一次或切换到近期截图。
- 通用、截图、标注、贴图、快捷键、输出六类设置。
- 设置自动保存、快捷键冲突提示和恢复默认。
- 明暗主题，以及常见 PC 分辨率下的合理布局。

### 4.2 第一阶段不做

- 真实系统屏幕采集、系统级全局快捷键或原生置顶窗口。
- 云同步、账号体系、团队协作和分享链接。
- 完整素材库、标签系统或跨设备历史。
- OCR、长截图、录屏和 AI 自动标注。
- 插件体系或第三方集成。

这些能力可以作为原生版本的后续路线，但不得让第一阶段原型变成重型编辑器。

## 5. 参考图能力映射

用户提供的五张 Snipaste 设置截图对应以下设计要求：

| 参考能力 | PinShot 设计落点 |
| --- | --- |
| 语言、开机启动、自动备份、快速响应、日志、配置文件 | “通用”页中的基础偏好与诊断分组 |
| 截图边框、遮罩、锚点、放大镜显示、十字线、快捷键提示 | “截图”页中的选区视觉和辅助信息分组，并提供即时预览 |
| 贴图阴影、右键菜单快捷键、透明度、最大尺寸、缩略图尺寸 | “贴图”页中的外观、行为和尺寸分组 |
| 截图、自动复制、自定义截图、贴图、贴图组快捷键 | “快捷键”页中的组合键录制器与冲突检测 |
| 贴图缩放、透明度、关闭、重置、缩略图、复制文本鼠标手势 | “贴图”页的鼠标操作映射器 |

## 6. 信息架构

PinShot 不设置传统的内容型首页。产品由四个主界面和一个辅助入口构成：

1. **截图蒙层**：负责选区与截图辅助信息。
2. **悬浮标注栏**：负责工具选择和输出动作。
3. **桌面贴图**：负责临时置顶参考。
4. **设置中心**：负责可配置行为。
5. **托盘菜单**：提供截图、贴图、设置、最近截图和退出入口；原型仅模拟菜单外观和行为。

## 7. 核心交互流程

### 7.1 快速截图并复制

1. 用户按 `F1`，界面进入截图蒙层。
2. 鼠标悬停时显示窗口候选边框；用户也可直接拖拽自由选区。
3. 松开鼠标后显示八个锚点、尺寸标签和标注栏。
4. 用户按 `Enter` 或点击“复制”。
5. 显示不阻断操作的成功提示，随后退出蒙层并回到模拟桌面。

目标：熟练用户从 `F1` 到复制可在 3 秒内完成。

### 7.2 截图并标注

1. 用户完成选区后选择矩形、箭头、画笔、荧光笔、文字、序号、马赛克或取色。
2. 工具的颜色、粗细或字号设置在工具栏旁展开，不覆盖选区主体。
3. 每次绘制形成一个可撤销操作；`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。
4. 用户复制、保存或将结果贴到桌面。

### 7.3 桌面贴图

1. 用户按 `F3` 或点击“贴图”，当前截图变为无边框悬浮卡片。
2. 拖拽卡片移动；滚轮缩放；`Ctrl + 滚轮` 调整透明度。
3. 悬停后显示锁定、旋转、复制、保存和关闭控制。
4. 双击卡片收起为快速缩略图；再次双击恢复。
5. 多张贴图可以作为一组隐藏或恢复，但第一阶段不提供复杂分组管理界面。

### 7.4 设置修改

1. 用户从托盘菜单进入设置中心。
2. 修改立即生效并自动保存，无需“应用”按钮。
3. 快捷键录制时若检测到产品内冲突，则就地说明冲突对象，并保留原值。
4. 每个设置分组提供“恢复本组默认”，窗口底部提供“恢复全部默认”。

## 8. 视觉设计

### 8.1 色彩

- 深石墨灰 `#171A1F`：截图工具栏和悬浮控件。
- 清透蓝 `#4C8DFF`：选区边框、当前工具和键盘焦点。
- 薄荷绿 `#2FC79A`：贴图成功、置顶和积极状态。
- 珊瑚红 `#F25F5C`：关闭、删除等危险操作。
- 浅色表面 `#F6F7F9` 与白色 `#FFFFFF`：设置中心背景和卡片。
- 深色正文 `#20242B`，次级文本 `#69707D`。

所有文本与背景组合应满足 WCAG AA 的常规文本对比度要求。

### 8.2 字体与尺寸

- 字体：`Segoe UI Variable`、`Microsoft YaHei UI`、系统无衬线字体。
- 正文 14px，辅助信息 12px，设置页标题 22px。
- 工具图标 20px，最小可点击区域 36 × 36px。
- 截图工具栏高 48px，设置窗口约 860 × 620px，左侧导航宽 176px。

### 8.3 截图蒙层

- 非选中区域使用约 55% 黑色蒙层。
- 选区保持原亮度，并使用 2px 蓝色描边。
- 尺寸标签默认位于选区左上角外侧，靠近屏幕边缘时自动翻转。
- 放大镜避让鼠标和屏幕边缘，可在设置中选择显示遮罩、边框或锚点。

### 8.4 悬浮工具栏

工具顺序固定为：

`选择｜矩形｜箭头｜画笔｜荧光笔｜文字｜序号｜马赛克｜取色 · 撤销｜重做｜复制｜保存｜贴图｜完成`

工具栏为半透明深色浮层，当前工具使用蓝色圆角底。鼠标停留 400ms 后显示工具名与快捷键。工具栏优先位于选区下方；空间不足时翻转到上方，仍不足时进入选区内侧但保持 12px 安全边距。

### 8.5 设置中心

- 左侧导航：通用、截图、标注、贴图、快捷键、输出。
- 中间内容使用分组标题、说明、开关、下拉框、数字输入和快捷键录制器。
- 需要视觉反馈的页面在右侧提供效果预览。
- 不使用参考图中的顶部密集页签和嵌套子页签。

## 9. 状态模型与组件边界

顶层状态依次为：

`idle → capturing → selected → annotating → copied | saved | pinned → idle`

`settings` 和 `history` 是可从 `idle` 进入的独立覆盖状态。`Escape` 按层级退出当前弹层、工具或截图流程。

### 9.1 Capture Overlay

职责：模拟桌面蒙层、窗口候选、自由选区、锚点调整、尺寸标签和放大镜。
输入：指针事件、键盘事件、截图偏好。
输出：规范化选区矩形与确认/取消事件。

### 9.2 Annotation Canvas

职责：管理标注对象、绘制预览、选中态和撤销/重做历史。
输入：选区内容、工具类型、样式和指针事件。
输出：标注操作列表与合成预览。

### 9.3 Action Toolbar

职责：展示工具和输出动作，仅派发指令，不直接保存绘制状态。
依赖：顶层状态和 Annotation Canvas 暴露的能力。

### 9.4 Pin Surface

职责：管理贴图位置、缩放、透明度、锁定、收起和悬浮控制条。
输入：合成截图与贴图偏好。
输出：贴图状态变更和关闭事件。

### 9.5 Settings Store

职责：统一保存主题、截图偏好、标注默认值、贴图行为、快捷键和输出设置。原型使用浏览器本地存储；无效或旧版本数据回退到默认配置。

### 9.6 History Strip

职责：保存当前会话中的近期截图缩略图和最近一次合成状态。第一阶段最多保留 8 张，不承担长期素材管理职责。

## 10. 原型数据流

1. 用户启动截图后，Capture Overlay 根据模拟桌面和指针生成选区矩形。
2. 选区确认后，顶层状态创建一次截图会话，并把选区交给 Annotation Canvas。
3. Annotation Canvas 将每个标注保存为结构化操作，合成预览只由这些操作派生。
4. Action Toolbar 发出复制、保存或贴图命令。
5. 输出服务生成可下载图像或原型内复制反馈；贴图命令则把合成结果交给 Pin Surface。
6. 设置更新先写入 Settings Store，再由订阅的界面即时响应。

原型不得把截图或设置发送到远端服务。

## 11. 键盘与鼠标约定

| 动作 | 默认输入 |
| --- | --- |
| 开始截图 | `F1` |
| 截图并自动复制 | `Ctrl+F1` |
| 自定义截图 | `Shift+F1` |
| 贴图 | `F3` |
| 隐藏/显示全部贴图 | `Shift+F3` |
| 切换贴图组 | `Ctrl+F3` |
| 确认/复制 | `Enter` |
| 取消/逐层退出 | `Escape` |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 贴图缩放 | 滚轮 |
| 贴图透明度 | `Ctrl + 滚轮` |
| 关闭贴图 | 左键双击，可配置 |
| 重置贴图 | 中键单击，可配置 |
| 快速缩略图 | `Shift + 左键双击`，可配置 |
| 复制文本 | `Shift + 右键单击`，可配置 |

原型只在浏览器页面获得焦点时响应这些按键，并在界面中说明该限制。

## 12. 错误与边界处理

- **选区过小**：吸附到最小有效尺寸，不弹出阻断式对话框。
- **工具栏越界**：按下方、上方、内侧的顺序自动重新定位。
- **快捷键冲突**：指出冲突动作，原值不被覆盖。
- **保存失败**：保留截图会话和标注，显示可重试提示。
- **本地设置损坏**：回退到默认值，并显示一次非阻断通知。
- **浏览器剪贴板权限不可用**：展示明确的原型反馈，并保留下载路径。
- **窗口失焦**：保留当前会话；重新聚焦后继续，不静默丢失标注。
- **多分辨率**：选区和贴图始终限制在原型桌面可视区域内。

## 13. 可访问性

- 所有图标按钮提供中文可访问名称和可见工具提示。
- 键盘焦点清晰可见，焦点顺序与工具栏视觉顺序一致。
- 颜色不作为唯一状态信号；选中、成功和错误同时使用图标或文字。
- 动画遵循系统“减少动态效果”偏好。
- 设置表单的标签、帮助文本和错误提示与控件建立明确关联。

## 14. 验证与测试

### 14.1 核心流程测试

- `F1 → 拖拽选区 → Enter` 可完成一次复制反馈并回到待机状态。
- 选区可通过八个锚点调整，尺寸标签同步更新。
- 每种标注工具至少能完成一次创建，并能撤销和重做。
- “贴图”能生成可移动卡片，滚轮缩放、透明度、锁定和关闭行为正确。
- 刷新后设置保持，恢复默认后回到规范默认值。

### 14.2 边界测试

- 选区靠近四个屏幕边缘时，尺寸标签和工具栏不越界。
- 快捷键冲突、剪贴板不可用和本地设置损坏时不会丢失当前会话。
- 1366 × 768、1440 × 900、1920 × 1080 三种桌面尺寸下保持可用。
- 深色和浅色主题都满足可读性与焦点可见性要求。

### 14.3 体验验收

- 首屏看起来像桌面截图工具，而不是网页仪表盘。
- 熟练用户可在 3 秒内完成无标注截图并复制。
- 常用动作位置稳定，不因工具切换发生跳动。
- 工具栏不会遮挡当前主要编辑区域。
- 参考图中的截图显示、贴图行为、快捷键和鼠标操作均有清晰配置入口。

## 15. 方案取舍

设计阶段比较了三条路线：

1. **捕捉优先**：操作最快、最符合桌面效率工具定位，作为本方案。
2. **素材库优先**：适合内容团队，但会增加主窗口和管理负担，第一阶段不采用。
3. **智能增强**：OCR、长截图和自动打码差异化更强，但会让首版变重，留作后续。

第一阶段通过浏览器原型验证体验，而不是立即开发原生应用。这样可以先确认选区、标注、贴图和设置的视觉与交互，再将稳定模型迁移到原生 Windows 技术栈。

## 16. 完成定义

设计目标只有在以下条件全部满足时才视为交付完成：

1. 高保真原型覆盖截图、标注、复制/保存、贴图和设置闭环。
2. 核心快捷键和鼠标手势可在页面焦点范围内演示。
3. 参考图涉及的设置能力全部有对应界面。
4. 原型通过核心流程、边界尺寸和设置持久化验证。
5. 提供可直接打开的本地入口及清晰的原型限制说明。
