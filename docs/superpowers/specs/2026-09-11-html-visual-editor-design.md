# HTML 可视化编辑器设计

日期：2026-09-11

## 目标

在上传记录操作栏增加“编辑”入口，使用户可以对已发布的单 HTML 文件进行可视化修改：

- 双击网页文字直接编辑文案。
- 选择网页区块后调整常用样式或直接编辑该元素的内联 CSS。
- 删除选中的网页模块，并支持撤销和重做。
- 保存后立即更新原访问链接，同时将保存前版本放入现有回滚槽。

## 已确认范围

- 首版仅支持 uploadKind 为 html 的单 HTML 文件。
- ZIP 网站包不显示可用的编辑入口，不修改 ZIP 文件或其中资源。
- 采用三栏工作台：左侧模块树、中间网页画布、右侧属性面板。
- 画布支持双击文字直接编辑。
- 样式面板包含常用可视化控件和高级 CSS。
- 单击画布时智能选择最近的有效区块，并支持切换父级和子级。
- 编辑画布暂停原 HTML 的 JavaScript；保存后的发布页面继续保留并执行原脚本。
- 保存即发布，不引入草稿状态。

## 交互设计

### 上传记录入口

- 单 HTML 记录的操作栏增加“编辑”按钮，进入 /editor.html?id=<record-id>。
- ZIP 记录不提供编辑按钮，避免给出不可用操作。
- 编辑页加载失败或记录已删除时显示明确错误，并提供返回上传记录的入口。

### 三栏工作台

- 顶部工具栏包含返回、页面标题、撤销、重做、预览、保存并发布。
- 左侧模块树展示 body 内可编辑元素的层级；选中节点与画布双向同步。
- 中间画布使用 iframe 渲染原页面，悬停显示候选区块，单击确认选中。
- 右侧面板显示所选元素类型、常用样式控件、高级 CSS 和删除操作。
- 小屏幕下模块树和属性面板改为可切换抽屉，画布保持主要空间。

### 文字、样式与模块

- 双击文本时选中最近的可编辑文本容器并进入内联编辑。
- 退出文字编辑时形成一条可撤销操作；空文本允许保留，不自动删除元素。
- 常用样式包括文字颜色、背景色、字号、字重、对齐、行高、宽高、内外边距、边框和圆角。
- 高级 CSS 编辑所选元素的 style 声明，不直接修改全局 style 标签或外部样式表。
- 模块删除作用于当前智能选中元素；删除前不弹阻塞确认框，但可立即撤销。
- html、head、body、script、style、link、meta、base、title 等基础节点不可删除。

### 撤销、重做与离开保护

- 使用操作栈记录文字、样式和删除变化，不为每一步复制整份 HTML。
- 撤销或重做后同步刷新模块树、选中框和属性面板。
- 有未保存修改时，返回上传记录、刷新或关闭页面会触发离开确认。
- 保存成功后清空脏状态和操作栈，并更新当前版本标识。

## 技术方案

### 管理端边界

- 编辑页面和源码接口仅存在于 admin 角色，继续使用 ho.wekki.fun 的登录会话。
- content 角色的路由白名单保持不变，只开放健康检查和 /view/:id。
- 编辑器从管理端受保护接口读取 HTML，不从 page.wekki.fun 跨域读取源码。

### 编辑画布

- 浏览器通过 DOMParser 解析原始 HTML。
- 为 body 内元素添加只存在于编辑会话中的节点 ID，用于连接模块树、画布和操作栈。
- 将文档写入 sandbox="allow-same-origin" 的 iframe，不授予 allow-scripts、表单提交、弹窗或顶层导航能力。
- 拦截画布内链接和表单默认行为，避免编辑时离开画布。
- 原 script 节点保留在 DOM 中，但因沙箱配置不执行。
- 保存前移除节点 ID、选中态和编辑器注入的临时节点，并恢复编辑器临时改动过的 contenteditable 与 spellcheck 属性原值。
- 保留原 doctype，并序列化完整文档。

### 智能模块选择

- 点击元素后从命中节点向上查找最近的语义区块或有布局意义的容器。
- 优先识别 section、article、header、footer、main、aside、nav、figure、table、form、列表项及具有可见盒模型的 div。
- 对纯文本元素、按钮、图片等叶子元素允许精确选中。
- 面包屑和模块树允许用户切换父级或子级，以覆盖自动判断不理想的情况。

## API 与存储

### 读取源码

新增管理端接口：

GET /api/uploads/:id/content

成功响应包含：

- 原始 HTML 文本。
- 公开记录数据。
- 当前内容版本标识，基于当前文件内容和记录状态生成。

仅允许读取单 HTML 记录；ZIP 返回 409。

### 保存源码

同一接口支持：

PUT /api/uploads/:id/content

- 请求体为 UTF-8 HTML，大小沿用 30 MB 上限。
- 请求携带读取时获得的版本标识。
- 服务端重新读取当前记录并校验版本；不一致时返回 409，阻止旧编辑会话覆盖新版本。
- 校验通过后进入现有 withRecordMutation 串行写入区。
- 先调用 savePreviousVersion(record)，再覆盖当前 HTML、更新文件大小、上传时间、描述和记录索引。
- 保存失败时保留当前发布版本；不得出现索引已更新但 HTML 未完整写入的状态。
- 成功返回更新后的公开记录和新版本标识。

## 安全设计

- 读取与保存接口同时经过服务器路由鉴权和 managementRequestFailure 校验。
- content 角色不注册编辑 API，防止从公开域名探测管理源码。
- iframe 不执行上传 HTML 中的脚本和内联事件处理器。
- 编辑器不将登录凭据、管理 API 地址或父页面对象注入上传文档。
- 保存接口只接受已存在的单 HTML 记录，不允许通过 ID 创建任意文件。
- HTML 大小、记录 ID、方法和内容类型均在服务端验证。
- 序列化清理使用白名单式编辑器属性清理，不删除用户原有脚本、样式或业务属性。

## 错误处理

- 401：登录失效，跳转登录页并保留编辑页返回地址。
- 404：记录不存在或文件已删除，显示不可编辑状态。
- 409：ZIP 不支持编辑、没有可用 HTML，或版本冲突；版本冲突提供重新加载。
- 413：保存内容超过 30 MB。
- 网络错误：保留浏览器中的未保存修改，允许重试保存。
- 序列化或存储错误：不清空脏状态和撤销栈。
- 保存按钮显示进行中状态并防止重复提交。

## 验证

- 服务端单元测试覆盖鉴权、HTML/ZIP 分支、读取、保存、版本冲突、30 MB 限制和回滚。
- 存储测试验证保存前版本可通过现有回滚操作恢复。
- 客户端测试覆盖智能选择、受保护节点、文本编辑、样式修改、删除、撤销/重做和序列化清理。
- 集成测试验证列表“编辑”入口、编辑保存、原公开链接更新以及 content 角色拒绝编辑 API。
- 使用含内联脚本、事件属性、复杂嵌套结构和中文文案的 HTML 做回归。
- 桌面和移动视口检查三栏布局、抽屉、选中框、属性面板和保存 loading，无重叠或横向溢出。

## 非目标

- 不编辑 ZIP 网站包。
- 不提供拖拽新增组件、模板市场或页面搭建能力。
- 不提供全局 CSS 文件、JavaScript 或 head 的源码编辑器。
- 不提供多人实时协作或多版本历史；继续沿用现有单个上一版本回滚模型。
- 不尝试把任意 HTML 转换为统一组件模型。
